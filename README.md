# Pulse E-commerce UI

A responsive single-page e-commerce experience built with Tailwind CSS and modern JavaScript. It features dynamic product rendering, category filters, search, cart count simulation, a theme toggle, and polished marketing sections for highlights, perks, and newsletter signup.

## Getting started

Open `index.html` in your browser to explore the experience. No build tools are required thanks to the Tailwind CDN and vanilla ES modules.
