# my-new-repo

A repository dedicated to Web Development, App Development, and Cybersecurity. The goal is to create secure, user-friendly web and mobile applications, while also implementing the latest cybersecurity practices to ensure the safety of users and systems.

## Ecommerce role-based dashboards

This repository now includes a static prototype that showcases role-specific dashboards for an ecommerce platform. Open `index.html` in a browser to explore the interactive tabs for Admin, Moderator, Editor, Cashier, and Customer roles. The layout highlights:

- Summary metrics per role
- Key responsibilities and quick actions
- Activity feeds to keep each persona focused on their tasks

Run locally by double-clicking `index.html` or serving the folder with any static web server.
